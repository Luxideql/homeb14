# UNI — единый торговый бот (копия демо-3 на homeb14)

Форвард-тест на **демо-счёте Bybit** (USDT-перпы, linear). Берёт сигналы входа
четырёх источников (MAIN A–D, RISK S1–S5, S6 T1–T3, S7 листинги) **без изменений**
и ведёт все позиции по единым правилам размера и выхода владельца.

Собрано **заново по спецификации** (`PROMPT_UNI_demo3` + `prompt_UNI_v1`), а не
скопировано из оригинала — поэтому индикаторы/фильтры могут отличаться в мелочах;
истина проверяется журналом форвард-сделок и офлайн-тестами. Детерминированный
скрипт на Python 3 (только стандартная библиотека), без LLM в контуре.

Отличие от спеки: код лежит в `/home/homeb14/strategy/` (а не `/opt/data/strategy/`),
чтобы работать без root и попадать в git-бэкап. Пути внутри кода — относительно
каталога скрипта. Логика входа/выхода — по спеке.

ATR-стоп 2.5·ATR + широкий трейлинг 3·ATR (активация +1·ATR), а не $-логика S6.

(через Tailscale) или по LAN. Читает `trades_log_uni.csv` + живые позиции с биржи,

Тёмный, мобайл-first, українською, без фреймворків. API: `/api` (JSON).

## Fail-closed (без этого — ни одного торгового действия)
`BYBIT_ENV=demo`, `BYBIT_PROFILE=uni`, ключ = ключу UNI, `/v5/user/query-api`
вернул userID = `UNI_EXPECT_USERID`. Иначе — выход с кодом 2 и «FATAL».
Изолированная маржа + one-way проверяются и восстанавливаются при запуске.

## Управление (файлы-флаги в `strategy/uni/`)
`DISABLE_UNI` — стоп всех входов (сопровождение продолжается);
`DISABLE_UNI_MAIN/_RISK/_S6/_S7/_TREND/_ADD` — по источникам/докупкам;
`DISABLE_TRAILING` — лесенка вместо трейлинга;
`DISABLE_LOSS_STOPS` — без стопов убытка (режим «только ликвидация»);
`ENABLE_TP100` — вернуть тейк +$100.

## Честно
По собственному бэктесту владельца похожий режим на истории — в минусе. Ценность
проекта — данные (`max_net_reached`, `min_net_reached`, `mae_pct`) для калибровки
стопов, а не доходность. Демо ≠ реал (особенно S7-листинги). Оценка — не раньше
30 дней / 60+ сделок по журналу.
